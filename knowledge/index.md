# Wuf knowledge bundle

Internal product and engineering knowledge for maintainers and coding agents.
This bundle follows the [Open Knowledge Format v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md).

# Start here

* [Documentation boundaries](documentation.md) - Decides what belongs in the README, public docs, and this bundle.
* [Product knowledge](product/) - CLI semantics, accuracy guarantees, and future product work.
* [Engineering knowledge](engineering/) - Architecture, development, release, and implementation constraints.
* [Update log](log.md) - Significant changes to this bundle, newest first.

# Reading policy

Read only the concepts relevant to the current task. Public behavior is
authoritative in the running CLI and tests; this bundle explains the durable
intent and engineering decisions around that behavior.
